# Supply Chain Value Streams

The value-stream view connects supply chain intent to measurable enterprise outcomes.

## Core Pattern

`Business Outcome → Value Stream → Capabilities → Processes → Decisions → Data → Applications → Technology → Experience → Outcome Measurement`

## Cross-Stream Value Streams

- Plan-to-Fulfill
- Source-to-Settle
- Order-to-Deliver
- Forecast-to-Plan
- Manufacture-to-Deliver
- Return-to-Recover
- Risk-to-Resilience
- Insight-to-Action
