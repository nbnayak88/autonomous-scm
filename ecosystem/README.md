# Supply Chain Ecosystem

The Autonomous SCM ecosystem is platform-neutral.

Enabling platforms may include SAP, Oracle, Kinaxis, Blue Yonder, Anaplan, AWS, Microsoft, Siemens, Rockwell Automation, Manhattan, MuleSoft, Boomi, Kafka and specialized solutions.

## Mapping Principle

Capability → Process → Use Case → Requirement → Platform Mapping

Platforms enable capabilities; they do not define the canonical capability model.
